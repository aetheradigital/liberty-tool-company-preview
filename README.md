# Liberty Tool Company — Website Preview

Static preview of libertytoolcompany.com, for review only (pages are set to `noindex`).

- `/` — Option 2 (Fun / Logo Blue)
- `/classic/` — Option 1 (Classic)

Plain HTML, no build step. `runtime.js` renders each page's template and runs the interactive pieces (Floor Finder, popups, Bid Builder, Quote List, kit builder, booking form). Nothing is stored or sent anywhere; forms are front-end only until wired to HighLevel and Shopify.

Deploy: Render static site, publish directory `.` (repo root), no build command.
